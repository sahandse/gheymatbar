== Description ==
Gheymatbar provides modular price widgets and shortcodes for gold, coins, currencies and cryptocurrencies.

== Installation ==
1. Upload the gheymatbar folder to /wp-content/plugins/
2. Activate the plugin.
3. Open قیمت‌بار from WordPress admin.
4. Add the desired shortcode to any page.
