# قیمت‌بار

افزونه نمایش قیمت‌های لحظه‌ای برای وردپرس با رابط فارسی، مینیمال و مناسب سایت‌های خبری و فروشگاهی.

## بخش‌ها
- طلا
- سکه
- دلار و ارزهای رایج
- رمزارزها
- شورت‌کد مجزا برای هر بخش
- نمایش افقی یا عمودی
- انتخاب تم و رنگ
- ساختار مناسب برای ویجت Elementor
